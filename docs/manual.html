Fluxo recomendado

  1. Cadastre a empresa em Clientes.
  2. Cadastre o caminhão e associe-o à empresa.
  3. Cadastre serviços e peças disponíveis.
  4. Abra uma Nova OS, escolha a empresa e adicione os caminhões.
  5. Inclua serviços e peças. O sistema valida estoque e calcula o total.
  6. Envie a OS para Revisão e aguarde a aprovação.
  7. Consulte a OS aprovada no Histórico e gere o PDF.
Os valores e relações são carregados do banco de dados; evite duplicar registros manualmente.

Cadastros e relações

O sistema trabalha com relações para manter os dados consistentes:

  • Empresa x Caminhão: todo caminhão deve possuir uma empresa associada.
  • OS x Empresa: cada ordem pertence a uma empresa.
  • OS x Caminhão: os itens da OS preservam placa, modelo, ano e cor.
  • OS x Serviço/Peça: os itens usam os IDs do cadastro e os valores oficiais.

Revisão de OS

Use as abas para alternar entre OS em revisão, aprovadas, reprovadas e todas. Os filtros permitem buscar por número, empresa, placa ou modelo.

  • Abra os detalhes para conferir cada caminhão.
  • Confira serviços, peças, quantidade, data e valores.
  • Aprove somente quando os dados estiverem corretos.
  • Reprove quando houver inconsistência e registre a correção no fluxo operacional.

Histórico e PDF

O Histórico mostra as OS aprovadas. Use a busca ou o filtro de empresa para encontrar um registro.

  1. Abra os detalhes da OS.
  2. Clique em Visualizar relatório completo.
  3. Confira empresa, caminhões, serviços, peças, quantidades e total.
  4. Clique em Baixar PDF. Relatórios longos são divididos automaticamente em páginas.
